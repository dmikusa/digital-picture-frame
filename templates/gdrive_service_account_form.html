Google Drive (Private, Service Account)

Use this for a private folder in your own Google Drive. The frame reads the folder with a service account you create, so no photos need to be shared publicly.

  1. Open console.cloud.google.com and select or create a project under your normal Google account.
  2. Enable the Google Drive API for that project.
  3. Create a service account, then create and download a JSON key for it.
  4. In Google Drive, create a normal folder and share it with the service account's email address as Viewer.
  5. Copy the folder ID from the folder's URL and paste it below with the JSON key.

The service account cannot own or create files, so create the folder with your own account and share it. The JSON key is a secret: anyone who has it can read every folder shared with that service account.
